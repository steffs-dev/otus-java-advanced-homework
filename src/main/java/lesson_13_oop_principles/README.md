
# ATM

> Проект реализует учебный банкомат с использованием паттернов:
>
>- **Command** — инкапсуляция операций (внесение, снятие, баланс)
>- **State** — управление состояниями сессии (меню, ввод суммы, выход)
>- **Builder** — создание `MoneyBox`
>- **Decorator** — `GlobalCommand` оборачивает команды для обработки ошибок
>- **Facade** — `AtmFacade` для инициализации
>- **Strategy** — UI интерфейс с реализацией `Console`
